# Lab2Web - Portal Mahasiswa (Praktikum HTML Lanjutan)

Repositori ini berisi kode untuk tugas praktikum Web Development (Lab2Web) yang berfokus pada penerapan Semantic HTML5, pembuatan tabel data, penyusunan form interaktif, serta penggabungan elemen multimedia (audio dan video).

## 📁 Struktur Direktori

Untuk memastikan web berjalan dengan baik, pastikan struktur folder Anda di komputer terlihat seperti ini:

Lab2Web
├── index.html # Halaman utama berisi navigasi dan implementasi multimedia
├── biodata.html # Halaman berisi tabel data mahasiswa dan form lengkap
└── media/ # Folder khusus untuk menyimpan aset media
├── file_example_MP3_700KB.mp3
└── file_example_MP4_640_3MG.mp4
